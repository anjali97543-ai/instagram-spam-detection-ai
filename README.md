# Instagram Spam Detection AI

## Overview
An AI-based system that detects:
- Spam Instagram comments
- Fake or suspicious accounts

## Technologies Used
- Python
- Machine Learning
- NLP
- Streamlit

## Modules

### Spam Comment Detection
Uses NLP and Machine Learning to classify comments as spam or genuine.

### Fake Account Detection
Uses account behavior analysis to detect suspicious accounts.

## Dataset
- 500 rows
- 26 features

## Application
Built using Streamlit dashboard.
